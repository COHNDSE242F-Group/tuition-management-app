# 📱 Tuition Management Information System (Android App)

## 🚀 Overview

The **Tuition Management Information System** is an Android-based mobile application designed to automate and simplify the management of tuition centers. It provides role-based access for **Admin, Teachers, Students, and Parents**, enabling efficient communication, attendance tracking, assignment handling, and academic monitoring.

The system uses **Firebase** as the backend for real-time database and notifications.

---

## 🎯 Features

### 👨‍💼 Admin

* Manage student and teacher accounts
* Assign students to classes/teachers
* View attendance reports and academic performance
* Manage overall system operations

### 👨‍🏫 Teacher

* Mark attendance using QR code scanning
* Upload assignments and course materials
* Enter and release student results
* Send notifications to students

### 👨‍🎓 Student

* View attendance records
* Access assignments and learning materials
* Submit assignments
* View results and performance
* Receive real-time notifications

### 👨‍👩‍👧 Parent 

* Monitor student attendance and results
* Receive updates and notifications

---

## 🛠️ Technologies Used

* **Language:** Java (Android)
* **IDE:** Android Studio
* **Backend:** Firebase Realtime Database
* **Notifications:** Firebase Cloud Messaging (FCM)
* **Version Control:** Git & GitHub

---

## 📡 System Architecture

* Mobile Application (Android)
* Firebase Backend (Realtime Database,Cloud Messaging)
* Role-based user system (Admin / Teacher / Student / Parent)
